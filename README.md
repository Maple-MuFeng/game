# 团本躲机制 · 剑网三小游戏

单文件网页小游戏：站在 Boss 的团本机制里，靠走位和蹑云活下来。

**双击 `index.html` 即可开玩**，无需安装、无需联网，桌面和手机通用。

---

## 操作

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 移动 | `WASD` / 方向键 | 左半屏按住拖动（摇杆跟手出现） |
| 蹑云（冲刺） | `空格` / `Shift` | 右半屏点按，或右下角「蹑云」按钮 |
| 暂停 | `P` / `Esc` | —（切后台自动暂停，点一下继续） |
| 重开 | `R` | 结算页点击屏幕 |
| 静音 | `M` | — |

蹑云带 0.26 秒无敌帧（五毒 0.44 秒），**用无敌帧从机制上滑过去**是这游戏最爽的地方。

## 玩法

Boss 每隔一段时间读条，地上出现预警圈。预警条填满即结算，站错位置就掉血，气血归零则结束。

- 每波 2～4 次读条，波次越高读条越短、连招越多
- 干净躲过一次 = **+10 + 连击 × 3**（藏剑 ×5），连击每层都在滚雪球
- 被击中则连击清零，并进入 0.7 秒受击无敌
- 每过一波 **额外 +40**，且读条间隔缩短
- 最高分存在浏览器本地（`jx3_dodge_best`），关掉再开还在

### 六种机制

| 机制 | 出现波次 | 应对 | 伤害 |
|---|---|---|---|
| 🔴 红圈「万钧·落」 | 1 | 站到圈外 | 26 |
| 🟣 点名「点名·裂」 | 2 | 圈会先跟你、后半段锁定，立刻跑开 | 26 |
| 🔺 扇形「分山·斩」 | 3 | Boss 朝你劈一刀，侧身闪 | 30 |
| 🔵 蓝圈「归元·阵」 | 4 | 反而要**站进去** | 26 |
| ✚ 十字「剑气」 | 5 | 离开十字带 | 24 |
| 🟣 追魂火球 | 6 | 会追着你跑，被沾到就掉血 | 18 |

第 4 波起可能同时出两个机制，第 10 波起有三个。

## 门派

七个门派共用同一套操作，差异在数值和特性。

| 门派 | 心法 | 气血 | 身法 | 蹑云 | 特性 |
|---|---|---|---|---|---|
| **纯阳** | 紫霞功 | 100 | 252 | 1.80 丈 / 0.95s | 一段蹑云最远，位移流 |
| **天策** | 傲血战意 | 132 | 286 | 1.38 丈 / 1.20s | 气血最厚、脚程最快，硬吃几下不倒 |
| **万花** | 离经易道 | 100 | 252 | 1.52 丈 / 1.10s | 每渡一波自回 8 点气血，长线最稳 |
| **刀宗** | 孤锋诀 | 105 | 262 | 1.50 丈 / 1.15s **×2** | 两段蹑云；无敌帧擦过刀锋额外 **+20** |
| **七秀** | 云裳心经 | 96 | 258 | 1.40 丈 / 1.05s | 每波一层「风袖」护盾，挡一次伤害且**不断连击** |
| **五毒** | 毒经 | 92 | 250 | 1.45 丈 / 1.05s | 「化蝶」无敌帧 0.44s（别人 0.26s），擦身更容易 |
| **藏剑** | 问水诀 | 98 | 268 | 1.60 丈 / 1.00s | 「剑意」连击分每层 +5（别人 +3），纯拼分 |

选门派建议：

- 想练走位 → **五毒**（无敌帧最长，容错最高）
- 想冲高分 → **藏剑**（连击滚起来分最快）
- 想稳 → **万花** / **七秀**（一个回血一个护盾）
- 手速自信 → **刀宗**（两段蹑云 + 擦刀奖励）

## 调试参数

地址栏追加查询参数。注意 `sect` 和 `w` 需要和 `auto`（或 `shot`）一起用，例如 `index.html?auto=1&w=8&sect=3`。

| 参数 | 作用 |
|---|---|
| `?auto=1` | 跳过标题页直接开局 |
| `?sect=N` | 指定门派，0 纯阳 / 1 天策 / 2 万花 / 3 刀宗 / 4 七秀 / 5 五毒 / 6 藏剑 |
| `?w=N` | 从第 N 波开始 |
| `?touch=1` | 强制显示触屏控件 |
| `?shot=1` | 固定步长推演到某张预警圈中途再渲染，用于截图与冒烟测试 |

## 想改数值

全部集中在 `index.html` 的几处：

- `SECTS` 数组 —— 门派数值与特性开关（`hp` / `speed` / `dashDist` / `dashCd` / `dashMax` / `heal` / `shield` / `iframe` / `comboGain`）
- `telegraph()`、`gapTime()` —— 读条时长与间隔随波次的变化曲线
- `buildPool()` —— 机制解锁顺序
- `resolveMechanics()` —— 命中判定、伤害与加分
